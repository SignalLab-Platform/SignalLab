Tests

This directory is reserved for tests that involve multiple SignalLab applications or the repository as a whole.

Application-specific tests remain colocated with their corresponding application structure:

* Backend tests will be initialized with the ASP.NET Core solution.
* Frontend tests will be initialized with the Next.js application.
* Cross-application integration and end-to-end tests may be added here when their supporting infrastructure exists.

No test framework is configured at this stage of the project.
